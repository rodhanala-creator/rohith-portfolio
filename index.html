CASE STUDY 01 // OPERATIONAL SYSTEMS AURA CLINICAL INTAKE

Aura Onboarding UX:
Re-Engineering Patient Registration

A complete clinical onboarding case study. Overhauling legacy non-responsive hospital forms with responsive pixel grids, progressive disclosure inputs, and automated emergency routing rules.

// FREELANCE ROLE: Lead Systems Architect
// PRIMARY ROI: Response Time < 2 mins
// TIMELINE: 12 Weeks Design-to-Live
// TECH STACK: Tailwind CSS, Make.com, Airtable

The Challenge: Sticky Notes and Inbox Clutter

A five-chair clinical dental practice was drowning in its own admin. Enquiries arrived scattered across three different websites, email forms, phone messages, and walk-in notebooks. Receptionists spent up to 15 hours a week sorting entries, matching calendars, and keying data manually.

The average response delay was over 6 hours. Critically, emergency cases (e.g. patients with severe pain or trauma) sat in the general inbox, occasionally getting lost, leading to lost client business and poor healthcare experiences.

The Strategy: Structural Intake & Triage Routing

The redesign replaced these scattered channels with a single, high-fidelity progressive disclosure form. I mapped patient onboarding into distinct stages (Basic details, Symptoms/Reason, Booking selection).

Behind the form sits a webhook system that parses inputs instantly. If the symptoms indicate trauma or throbbing pain, the system flags the patient as Urgent, alerts the clinic staff via mobile SMS instantly, and puts them at the top of an emergency callback queue. Routine check-ups receive an automated friendly confirmation and calendar booking match within 90 seconds.

CASE STUDY 02 // SECURE B2B PORTALS CLIENTBRIDGE GATEWAY

ClientBridge Gateway:
Streamlining Secure Document Sharing

A private document sharing and project timeline tracker. Overhauling messy B2B file sharing processes with single-client key access, auto-validation, and milestones.

// FREELANCE ROLE: Lead Full Stack Developer
// SYSTEM SECURITY: End-to-End Encryption
// TIMELINE: 6 Weeks Sprint Delivery
// TECH STACK: Vanilla JS, Airtable API, Resend

The Challenge: Lost Files and Communication Lag

A premium consulting firm managing clients was constantly chasing information. Financial documentation, tax files, and asset lists were sent over loose email threads, Dropbox links, and Slack channels. Important spreadsheets would get buried or expire, leading to projects stalling.

Furthermore, clients had no central location to view their project milestone statuses. They sent frequent "Any updates on our file?" messages, eating up hours of account managers' time every week.

The Strategy: Secure Vault & Live Project Milestones

I built a private B2B portal that acts as a secure file conduit and live tracker. Rather than requiring complex user accounts, clients log in with a single unique client access code mapping to their workspace.

Inside, the client can drag-and-drop confidential files. Each upload triggers an automated webhook listener, generating a file hash key, uploading the file securely, and updating a central Airtable ledger. The timeline updates immediately, displaying checkmarks as deliverables are verified, and account staff receive Slack notifications.

CASE STUDY 03 // AGILE PIPELINES FLOWPILOT SPRINT BOARD

FlowPilot:
Dynamic Kanban Pipeline Architecture

An interactive project sprint tracker. Rebuilding manual task routing into real-time drag-and-drop boards linked directly with backend operational sync.

// FREELANCE ROLE: Design Systems Developer
// METRICS SYNC: Lead Conversion +11%
// DURATION: 8 Weeks Sprint cycle
// PLATFORM STACK: HTML, CSS Grid, LocalStorage

The Challenge: Lost Opportunities and Invisible Deadlines

A regional logistics and maintenance business receiving plenty of website leads had no unified board to track them. Incoming service calls, boiler repair requests, and estimate surveys were scattered across sticky notes, personal calendars, and email checklists.

Managers had no way of seeing bottlenecks, such as having too many leads stuck in the "Contacted" stage without booking dates, or dispatchers dropping balls on confirmed slot assignments.

The Strategy: Focused Pipeline Grid

I designed FlowPilot: a developer-centric Kanban engine monitoring active operational pipelines. Instead of standard corporate complexity, it focuses on four simple metrics: New, Contacted, Qualified, Booked.

Whenever a lead moves across columns, the system logs the transaction instantly in the activity feed, calculates lead aging, and syncs status updates to Airtable databases. Moving a lead to "Booked" automatically triggers calendar entry creations and alerts dispatchers via Slack channels.

CASE STUDY 04 // AI AUTOMATION NEURAL NEXUS NLP TERMINAL

Neural Nexus:
Autonomous NLP Lead Extraction Engine

An autonomous natural language extraction node. Parsing unformatted client text messages into validated, schema-compliant JSON objects to sync with CRM fields.

// FREELANCE ROLE: Lead Systems Architect
// CRM EFFICIENCY: 92% CRM Entry Saved
// DEVELOPMENT: 4 Weeks Build Cycle
// TECH STACK: Node.js, OpenAI API, Webhook endpoints

The Challenge: Manual Transcription Exhaustion

A growing coaching and advisory institute received over 50 intake enquiries every single day. However, clients didn't use structured forms—they sent long, descriptive emails, LinkedIn messages, or voice note text transcriptions detailing their backgrounds, budgets, and operational issues.

Staff spent between 3 to 4 hours every day copy-pasting this information into Salesforce, mapping budgets to price tiers, extracting contact info, and writing summaries. The manual copying led to constant typos and data omissions.

The Strategy: Autonomous Webhook Schema Extraction

I designed and engineered Neural Nexus: an autonomous NLP parsing endpoint. Whenever an email or message is received, a Make.com webhook captures the payload and dispatches it to a private Node.js extraction script.

The node utilizes OpenAI's structured outputs API to parse the text against a strict JSON schema. It extracts Name, Email, Budget, Pain Points, and maps interest tiers (High/Medium/Low). The validated JSON is dispatched straight to Salesforce APIs and updates the team Slack channel with clean summaries within 3 seconds.
